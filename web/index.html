01
Scale-Invariant Ordinal Formulation

Monocular imagery lacks parallax disparity, rendering absolute metric depth in meters mathematically ill-posed without calibrated camera intrinsics. Continuous relative ordinal ordering (dA < dB) is fundamentally scale- and shift-invariant, generalizing zero-shot across diverse cameras and lens optics.

02
Koschmieder Optical Scattering Prior

Standard visual CNNs treat scenes as unconstrained RGB textures. The PINN formulation couples visual representations with Koschmieder's physical extinction law (I = J • t + A(1 − t)), penalizing non-physical depth predictions and ensuring monotonic distance ordering in hazy landscapes.

03
Multi-Spectral Dynamic Relief (MSX)

Direct colormapping of continuous depth fields tends to blur adjacent foreground objects into a singular visual cluster. MSX unsharp-masking extracts high-frequency RGB luminance gradients (∇Ihighpass) to modulate the thermal palette, preserving distinct object boundaries (e.g., foliage, vehicles, structures).

04
Real-Time Latency & Efficiency

Built upon a lightweight ResNet-18 backbone with a 4-stage residual FPN decoder (~12.4M parameters). Operates with sub-25ms inference latency (>40 FPS on standard RTX GPUs), ensuring feasibility for embedded robotics, autonomous drones, and low-power edge vision.

PINNDepthNet Architecture: Dual-Head Physics Network

The core neural network couples a multi-scale ResNet-18 visual feature extractor with two specialized heads: (1) Relative Depth Head producing continuous depth normalized strictly to [0.0, 1.0], and (2) Atmospheric Physics Head predicting global airlight vector A and extinction coefficient β. The DifferentiableAtmosphericLayer couples both outputs via Koschmieder's physical law.

Physical Transmission Law: t(x) = exp(−β • d(x))  ⇒  J(x) = (I(x) − A) / max(t(x), ε) + A

# Physics-Informed Neural Network (PINN) for Relative Depth Estimation
# =========================================================================
import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Dict, Tuple

from .encoder import ResNetEncoder
from .decoder import FeaturePyramidDecoder


class RelativeDepthHead(nn.Module):
    """
    Continuous Relative Depth Prediction Head.
    Maps decoded features [B, 32, H, W] to relative depth [B, 1, H, W] in [0, 1].
    - d(x) -> 0.0: Nearest foreground object
    - d(x) -> 1.0: Farthest background object / sky horizon
    """
    def __init__(self, in_channels: int = 32):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, 16, kernel_size=3, padding=1, bias=True)
        self.act = nn.ELU(inplace=True)
        self.conv2 = nn.Conv2d(16, 1, kernel_size=1, bias=True)
        self.sigmoid = nn.Sigmoid()

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.sigmoid(self.conv2(self.act(self.conv1(x))))


class AtmosphericPhysicsHead(nn.Module):
    """
    Estimates global airlight vector A in [0.5, 1.0]^3 and attenuation beta in [0.2, 3.0]
    from top semantic feature C5 [B, 512, H/32, W/32].
    """
    def __init__(self, in_channels: int = 512):
        super().__init__()
        self.pool = nn.AdaptiveAvgPool2d(1)
        self.fc = nn.Sequential(
            nn.Linear(in_channels, 64),
            nn.ELU(inplace=True),
            nn.Linear(64, 4),  # [A_r, A_g, A_b, beta]
        )

    def forward(self, c5: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor]:
        feat = self.pool(c5).flatten(1)
        params = self.fc(feat)
        airlight = 0.5 + 0.5 * torch.sigmoid(params[:, :3]).view(-1, 3, 1, 1)
        beta = 0.2 + 2.8 * torch.sigmoid(params[:, 3:]).view(-1, 1, 1, 1)
        return airlight, beta


class PINNDepthNet(nn.Module):
    """Unified Physics-Informed Relative Monocular Depth Network."""
    def __init__(self, backbone: str = "resnet18", pretrained: bool = True):
        super().__init__()
        self.encoder = ResNetEncoder(backbone=backbone, pretrained=pretrained)
        self.decoder = FeaturePyramidDecoder(encoder_channels=self.encoder.channels)
        self.depth_head = RelativeDepthHead(in_channels=self.decoder.out_channels)
        self.physics_head = AtmosphericPhysicsHead(in_channels=self.encoder.channels[-1])

    def forward(self, x: torch.Tensor) -> Dict[str, torch.Tensor]:
        features = self.encoder(x)                             # [C1, C2, C3, C4, C5]
        decoded = self.decoder(features, target_size=x.shape[-2:]) # [B, 32, H, W]
        depth = self.depth_head(decoded)                        # [B, 1, H, W] in [0, 1]
        airlight, beta = self.physics_head(features[-1])       # Global atmosphere
        transmission = torch.exp(-beta * depth)                  # Koschmieder t(x)
        return {"depth": depth, "airlight": airlight, "beta": beta, "transmission": transmission}

Multi-Scale Feature Pyramid Decoder with Residual Blocks

The decoder fuses deep semantic features (which encode scene context and object classification) with early lateral skip connections (which preserve razor-sharp pixel edges and boundary contours). Each stage applies a 1x1 Lateral Projection, Bilinear 2x Upsampling, 3x3 Channel Fusion, and a ResidualBlock that prevents vanishing gradients.

Stage Equation: F_i = ELU(BatchNorm(Conv3x3(Concat(Upsample(D_{i+1}), Proj(C_i)))))  →  D_i = F_i + ResConv(F_i)

# =========================================================================
# Multi-Scale FPN Decoder with Residual Refinement
# =========================================================================
import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import List


class ResidualBlock(nn.Module):
    """Refines spatial feature representations while preserving high-frequency gradients."""
    def __init__(self, channels: int):
        super().__init__()
        self.conv1 = nn.Conv2d(channels, channels, kernel_size=3, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(channels)
        self.act = nn.ELU(inplace=True)
        self.conv2 = nn.Conv2d(channels, channels, kernel_size=3, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(channels)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.act(self.bn2(self.conv2(self.act(self.bn1(self.conv1(x))))) + x)


class DecoderStage(nn.Module):
    """Individual Decoder Stage with Lateral Skip Projection and 2x Bilinear Upsampling."""
    def __init__(self, in_channels: int, skip_channels: int, out_channels: int):
        super().__init__()
        self.skip_proj = nn.Sequential(
            nn.Conv2d(skip_channels, out_channels, kernel_size=1, bias=False),
            nn.BatchNorm2d(out_channels),
            nn.ELU(inplace=True),
        )
        self.fuse_conv = nn.Sequential(
            nn.Conv2d(in_channels + out_channels, out_channels, kernel_size=3, padding=1, bias=False),
            nn.BatchNorm2d(out_channels),
            nn.ELU(inplace=True),
        )
        self.refine = ResidualBlock(out_channels)

    def forward(self, x: torch.Tensor, skip: torch.Tensor) -> torch.Tensor:
        skip_feat = self.skip_proj(skip)
        x_up = F.interpolate(x, size=skip_feat.shape[-2:], mode="bilinear", align_corners=True)
        fused = self.fuse_conv(torch.cat([x_up, skip_feat], dim=1))
        return self.refine(fused)


class FeaturePyramidDecoder(nn.Module):
    """Hierarchical Decoder combining C1 through C5 to native resolution [B, 32, H, W]."""
    def __init__(self, encoder_channels: List[int] = [64, 64, 128, 256, 512]):
        super().__init__()
        self.out_channels = 32
        c1, c2, c3, c4, c5 = encoder_channels
        self.top_proj = nn.Sequential(nn.Conv2d(c5, 128, 1, bias=False), nn.BatchNorm2d(128), nn.ELU(True), ResidualBlock(128))
        self.stage4 = DecoderStage(128, c4, 128)
        self.stage3 = DecoderStage(128, c3, 128)
        self.stage2 = DecoderStage(128, c2, 128)
        self.stage1 = DecoderStage(128, c1, 64)
        self.final_stage = nn.Sequential(nn.Conv2d(64, 32, 3, padding=1, bias=False), nn.BatchNorm2d(32), nn.ELU(True), ResidualBlock(32))

    def forward(self, features: List[torch.Tensor], target_size=None) -> torch.Tensor:
        c1, c2, c3, c4, c5 = features
        d1 = self.stage1(self.stage2(self.stage3(self.stage4(self.top_proj(c5), c4), c3), c2), c1)
        out = F.interpolate(d1, size=target_size, mode="bilinear", align_corners=True)
        return self.final_stage(out)

Rather than training on noisy, uncalibrated absolute depths, our objective combines: (1) Pairwise Relative Depth Ranking Loss sampling pairs (p0, p1) and penalizing order reversals, (2) Koschmieder Transmission Consistency ensuring physical haze extinction matches depth, and (3) Edge-Aware Smoothness allowing sharp depth jumps only at true visual image contours.

# =========================================================================
# Physics-Informed Relative Depth Losses
# =========================================================================
import torch
import torch.nn as nn
import torch.nn.functional as F


class RelativeDepthRankingLoss(nn.Module):
    """
    Pairwise Ordinal Ranking Loss for relative depth.
    Samples random pixel pairs and penalizes depth ordering violations:
        loss = log(1 + exp(-l_k * (d_pred_0 - d_pred_1)))
    """
    def __init__(self, num_pairs: int = 5000, margin_tau: float = 0.03):
        super().__init__()
        self.num_pairs = num_pairs
        self.margin_tau = margin_tau

    def forward(self, pred: torch.Tensor, gt: torch.Tensor, mask: torch.Tensor = None) -> torch.Tensor:
        B, _, H, W = pred.shape
        if mask is None:
            mask = (gt > 0) & torch.isfinite(gt)

        total_loss = torch.tensor(0.0, device=pred.device)
        for b in range(B):
            indices = torch.nonzero(mask[b, 0])
            if len(indices) < 100: continue
            N = min(self.num_pairs, len(indices) // 2)
            i0 = torch.randint(0, len(indices), (N,))
            i1 = torch.randint(0, len(indices), (N,))
            diff_gt = gt[b, 0, indices[i0, 0], indices[i0, 1]] - gt[b, 0, indices[i1, 0], indices[i1, 1]]
            diff_pr = pred[b, 0, indices[i0, 0], indices[i0, 1]] - pred[b, 0, indices[i1, 0], indices[i1, 1]]

            labels = torch.zeros_like(diff_gt)
            labels[diff_gt > self.margin_tau] = 1.0
            labels[diff_gt < -self.margin_tau] = -1.0

            ineq = labels != 0
            if ineq.any():
                total_loss += torch.log1p(torch.exp(-labels[ineq] * diff_pr[ineq])).mean()
        return total_loss / max(1, B)


class PhysicsConsistencyLoss(nn.Module):
    """Koschmieder physical reconstruction loss: ||I - [J*t + A*(1 - t)]||_1"""
    def forward(self, image, pred_depth, airlight, beta) -> torch.Tensor:
        t = torch.exp(-beta * pred_depth)
        j = torch.clamp((image - airlight) / torch.clamp(t, 1e-4) + airlight, 0.0, 1.0)
        reconstructed = j * t + airlight * (1.0 - t)
        return F.l1_loss(reconstructed, image)

FLIR MSX Dynamic Detail Embossing & Tone Expansion

Standard thermal imaging algorithms blur adjacent objects into a monochromatic bunch. FLIR MSX (Multi-Spectral Dynamic Imaging) uses an edge-guided high-pass filter on the visible RGB luminance channel and embosses the physical relief onto the false-color thermal depth map. Coupled with Adaptive Percentile Contrast Expansion (1.35x Gamma), individual plants, petals, vehicles, and structures remain distinctly identifiable.

MSX Relief Equation: H(x) = Y_{gray}(x) − GaussianBlur(Y_{gray}, σ=1.3)  ⇒  C_{fused} = C_{thermal} • [(1 - s) + 2s(0.5 + 2.4 H(x))]

# =========================================================================
# FLIR MSX Dynamic Detail Embossing & Tone Expansion
# =========================================================================
import cv2
import numpy as np


def apply_flir_msx_detail_embossing(
    thermal_rgb: np.ndarray,
    img_rgb: np.ndarray,
    strength: float = 0.55,
) -> np.ndarray:
    """
    Extracts high-frequency visual edge relief from RGB luminance and
    embosses it directly onto the thermal depth map, achieving authentic FLIR MSX clarity.
    """
    if strength <= 0.001:
        return thermal_rgb

    # Step 1: Extract luminance from RGB
    gray = cv2.cvtColor(img_rgb, cv2.COLOR_RGB2GRAY).astype(np.float32) / 255.0

    # Step 2: High-pass spatial edge filter via unsharp masking
    blur = cv2.GaussianBlur(gray, (0, 0), sigmaX=1.3)
    highpass = gray - blur

    # Step 3: Modulate thermal pixel luminance while strictly preserving color hues
    edge_relief = np.clip(0.5 + 2.4 * highpass, 0.0, 1.0)
    thermal_float = thermal_rgb.astype(np.float32) / 255.0
    modulator = (1.0 - strength) + (2.0 * strength) * edge_relief[:, :, np.newaxis]
    fused = np.clip(thermal_float * modulator, 0.0, 1.0)
    return (fused * 255.0).astype(np.uint8)


def enhance_depth_contrast(depth: np.ndarray, gamma: float = 1.35) -> np.ndarray:
    """Stretches active percentile dynamic range and expands midtone separation."""
    p1, p99 = np.percentile(depth, 1.0), np.percentile(depth, 99.0)
    stretched = np.clip((depth - p1) / max(p99 - p1, 1e-5), 0.0, 1.0)
    return np.power(stretched, gamma)
